# Heiltsuk_Camera_Project_MSOM
Code and data for two single-season multi-species occupancy models (MSOMs) of wolves and deer in Heiltsuk Territory. This analysis was conducted by Johanna Griggs as part of the Heiltsuk Camera Trap Project, a partnership between the UVic Applied Conservation Science Lab and the Heiltsuk Integrated Resource Management Department (HIRMD; Bella Bella, BC).
